# Mgame-FCash-auto-tasks

Windows 上的「领现金」每日任务助手。通过 USB 在已授权的 Android 手机上依次完成已核对的五项浏览任务。程序从手机界面读取进度，按剩余次数续跑。

## 手机和电脑怎么准备

1. 手机开启 USB 调试，用数据线连接电脑并解锁。接受手机上的调试授权，保持 1080×2400 竖屏。使用小米手机时，如果截图能读到但点击无响应，再检查「USB 调试（安全设置）」。
2. 手机打开「天天领现金」，停在游戏首页或右下角「任务」打开的「每日任务」。
3. 在 Windows 安装 Android Platform Tools 和简体中文 OCR。用 `adb devices -l` 核对连接。在仓库根目录准备 Python 环境。

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
```

```powershell
# 只识别当前可见任务
.\.venv\Scripts\python.exe -X utf8 .\fcash.py

# 按顺序执行剩余任务
.\.venv\Scripts\python.exe -X utf8 .\fcash.py --execute

# USB 重连并回到游戏后，只续跑浏览好物
.\.venv\Scripts\python.exe -X utf8 .\fcash.py --execute --task goods
```

只有一台已授权真机时会自动选择。多台手机时加 `--serial <序列号>`。可加 `--task goods --limit 1` 单独跑好物一轮。原有 `run.ps1` 也可以作为启动入口。

| 顺序 | 参数 | 任务 |
|---|---|---|
| 1 | `page` | 浏览页面领奖励 |
| 2 | `browse12` | 完成浏览领奖励（红包图标） |
| 3 | `promo` | 浏览优惠活动 |
| 4 | `browse14` | 完成浏览领奖励（紫色播放图标） |
| 5 | `goods` | 浏览好物 5 秒领奖励 |

放置区满时，程序会回游戏首页，间隔 5.5 秒执行 10 次一键合成，再打开「每日任务」。如果停在未知页面，先查看窗口里的停止原因和运行记录，再从游戏首页或任务列表续跑。

## 日常任务中断与续跑

- 执行日常任务时，若 USB 断开，程序会等待原设备重新连接，最多 30 秒。回到游戏后程序会重读当前任务次数。若断开前的领取或点击结果仍不明确，会停下等待核对。
- 识别到「身份核实」或滑块验证时会立即停止。完成验证后，可用对应的 `--task` 单项续跑。已确认是程序打开的落地页时，可加 `--recover-landing`。
- 领取奖励后若任务行消失且次数未确认清零，程序会记录该项并继续本批其他任务。批次末尾会显示部分完成。
- 长滑动重叠检查未通过时，本次运行后续查找沿用短滑动。若已确认的首页商品浮层挡住合成或任务入口，程序会先关闭浮层，再识别目标按钮。

## 游戏主页捕捉

全量日常批次（`--execute`）执行到末尾时，程序会关闭已确认的「每日任务」面板，回到游戏主页检查左下第二个「捕捉」。只根据入口是否有红点判断。无红点就跳过，有红点才打开面板，确认「马上捕捉」或橙色「去捕捉」可用时点击一次。

也可以单独运行捕捉。预览时请先回到游戏主页。

```powershell
# 检查入口提示
.\.venv\Scripts\python.exe -X utf8 .\fcash.py --task capture

# 有红点时执行一次捕捉
.\.venv\Scripts\python.exe -X utf8 .\fcash.py --task capture --execute
```

## 2026-11-25 复测与修复

| 真机现象 | 本次处理 |
| --- | --- |
| 两次广告返回后，任务面板在脚本超时后才出现 | 已点击任务入口且仍在游戏前台时，额外重查一次，窗口为 5 秒。重查期间等待现有面板，避免再次点击入口。 |
| 切换前台时同步截取诊断图，出现 8 次取帧超时 | 前台切换继续记录应用和 Activity。识别流程按需取帧，停止时保存已有证据和现场截图。 |

| 紫色播放跳到番茄畅听，好物落到两个新布局 | 等番茄畅听完成启动，只对实测落地页走原广告返回与结算核对。好物识别「限时优惠＋更多优惠」及「购买须知＋加入购物车」，操作限于浏览与返回。 |

## 2026-11-23 复测与修复

| 日常批次结束后需要检查免费捕捉 | 回游戏主页，只以左下「捕捉」入口的红点决定是否打开。打开后只选择已确认的免费按钮一次。 |

## 2026-11-22 更新
